# Windows Companion implementation checklist

## Core platform

- [x] Floating top-centre companion with hover expansion
- [x] Local Ollama chat and capability-aware model selection
- [x] Encrypted multi-account Google credentials
- [x] Role-based account switching with a configurable primary account

- [ ] Source citations in assistant responses
